koh — peer-to-peer remote shell, headless jobs, delta sync, and fux sessions over iroh QUIC.

SERVER is a saved name (`koh servers add NAME ID [--direct IP:PORT | --relay-url URL]`) or an
endpoint id. Only `connect` needs a terminal.

Keys & peers:
  koh id [client|server]                         print endpoint id (creates key if missing)
  koh key reset [client|server] --yes            delete key; next use generates a new id
  koh servers [add NAME ID [--direct IP:PORT | --relay-url URL] | rm NAME | rename OLD NEW]
  koh clients [add NAME ID [--cp DIR | --exec DIR] | rm NAME | rename OLD NEW]
  koh serve [--direct BIND] [--allow ID]... [--shell PROG] [--no-relay]
            [--max-connections N] [--max-sessions N]   (1 to 65535, 64 each; past them a client exits 75)
            (needs kill(1) on its PATH: jobs are ended and commands hung up with it;
             and id(1) where XDG_RUNTIME_DIR is not set: its state is kept under `id -u`)

Raw commands (no PTY; separate stdout/stderr; stdin EOF; hangup on drop):
  koh exec SERVER [--sync DIR] [-C DIR] [--json] -- PROG ARG...
  koh exec SERVER [--sync DIR] [-C DIR] [--json] --sh 'SHELL LINE'

Headless persistent jobs (raw append-only logs; outlive koh and network drops):
  koh run SERVER [--name NAME] [--sync DIR] [-C DIR] [--json] -- PROG ARG...
  koh jobs SERVER [NAME] [--json]
  koh logs SERVER NAME [--tail N | --all] [-f|--follow]
  koh wait SERVER NAME [--text SUBSTR] [--tail N] [--timeout SECS] [--json]
  koh kill SERVER NAME [--signal TERM|KILL|INT|HUP] [--json]

Delta file sync (blake3 hashes, atomic replace):
  koh cp [-r] [--delete] [--exclude PAT]... [-p] [--dry-run] [--json] SRC... SERVER:DST
  koh cp [-r] [--delete] [--exclude PAT]... [-p] [--dry-run] [--json] SERVER:SRC... DST

Sessions (each a fux pane on the server, in koh's own fux session, kept by `koh hold`;
`koh serve` prints the folder, and `koh fux view FOLDER` there shows them all as tabs):
  koh connect SERVER [--session NAME | --new] [-C DIR] [-- PROG ARG...]
            the session NAME, started if there is none; with no name the newest that lives,
            or a new one (always with --new or a program). Leave with Ctrl-] . or C-b d.
            Ends with the session's program: its status, 128+N if signal N ended it, 1 if
            nothing says how it ended.
  koh mount SERVER [--session NAME | --new] [DIR] [-- PROG ARG...]
            the same session as a folder: a mirror for `koh fux view`, `cat` or a script, in DIR
            (koh makes it; one that is there is not taken) or in koh's own fux session here
            ($XDG_RUNTIME_DIR/koh/fux/koh-mounts/SERVER.NAME, else ~/.cache/koh/...). Removed
            when the session ends or koh is stopped (SIGINT, SIGTERM).
  koh fux ...                                    fux itself, the one that reads koh's panes
  koh sessions | output | wait --session         not in this build: a session's files are on
            the server, where `koh exec` reads them

Global options: --key-file PATH, --direct IP:PORT, --relay-url URL, --json
Exit codes: 0 ok, 1 failed, 2 usage, 3 unreachable, 4 refused/out-of-scope, 75 busy,
            124 timeout, 126 cannot start, 127 not found, 255 koh internal error.
            (`exec`, `wait`, and `logs -f` exit with the remote command's exit status.)
            `koh serve` exits 75 when another `koh serve` already holds its key.
